# Rehearsal Evidence

`l-bracket/` is generated by the production headless rehearsal command. It
contains two consecutive release-candidate runs and the aggregate
`sha256-manifest.json`. The catalog covers regular files in each project's
canonical and recovery generations plus its exports; catalog files are
excluded to avoid circular hashes.

Regenerate it from a clean checkout with the pinned CI environment and a real
OCCT worker:

```bash
cargo run -p threeterm-cli --bin threeterm -- \
  --machine rehearse \
  --output-dir docs/research/rehearsal-evidence/l-bracket \
  --release-candidate rc-1
```

The integration test `committed_rehearsal_evidence_has_a_reproducible_sha256_catalog`
recomputes the catalog from the committed files without starting native
workers.
