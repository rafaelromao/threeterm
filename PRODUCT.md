# Product

## Register

brand

## Users

Linux terminal enthusiasts who do hobby 3D printing. They want to make functional
parts, understand the keyboard workflow, and get an editable project and an STL
into their existing slicer.

## Product Purpose

Present ThreeTerm's current terminal-native CAD capabilities honestly and make
the path from installation to a first part easy to follow. The landing page is
a static GitHub Pages site; the application remains a local Rust/C++ tool.

## Brand Personality

Warm, practical, mechanical. The user chose a maker-workbench presentation with
real screenshots, part-making examples, and clear installation instructions.

## Anti-references

Avoid generic SaaS dashboards, invented app mockups, and promises of a polished
form-based CAD interface. Current modeling inputs are typed JSON command drafts.

## Design Principles

- Show the actual tool and a real printable part.
- Lead with the hobbyist's task, then explain the commands.
- Put platform requirements beside installation instructions.
- Make the distinction between interactive and headless tools explicit.
- Keep setup and feature claims tied to the source.

## Accessibility & Inclusion

The user approved accessible defaults: keyboard navigation, readable contrast,
responsive layout, reduced-motion support, and descriptive image text.
